# 🛒 GroceryHub

**GroceryHub** is an online grocery platform that allows users to browse products, add them to their cart, and place secure orders with Stripe payments.
It includes a full admin dashboard to manage products, users, and orders, for a simple and smooth shopping experience.

---

## 🚀 Features

- 🔐 **Authentication System** — Built with **Laravel Breeze** for secure login, registration, and password reset.
- 🛍️ **Product Catalog** — Interactive product list with **search**, **filters**, and **sorting** options.
- 🧾 **Order Management** — Customers can place, view, and cancel orders.
- 💳 **Stripe Payments** — Secure and fast online payment integration.
- 📩 **Email Notifications** — Sending updates via email.
- 🧠 **Admin Dashboard** — Manage users, products, and orders....
- 💻 **Responsive Interface** — Modern design built with **HTML**, **CSS**, **JavaScript**, and **Bootstrap**.

## ⚙️ Installation

1. **Clone the repository**
```bash
    git clone https://github.com/usf54/groceryhub.git
    cd groceryhub

2. **Install backend dependencies**
    composer install
    cp .env.example .env
    php artisan key:generate
3. **Install frontend dependencies**
    npm install
4. **Set up your database**
5. **Run migrations**
6. **Start the development server**
    npm run dev
    php artisan serve

##🧠 Usage
Users can browse groceries, search items, add to cart, and complete purchases securely.
Admins can manage products, view user data, and track orders.
